# 智生活——AI 輔助學習系統 宣傳遊戲

「智生活——AI 輔助學習系統」專題的配套宣傳小遊戲，以 Godot 4 開發。

## 專案簡介

為配合專題展示與競賽宣傳所製作的動作生存遊戲，玩法類似吸血鬼倖存者（Vampire Survivors），讓觀眾在體驗遊戲的同時認識專題主題。

## 已完成功能

- 主選單介面
- 角色移動與射擊
- 敵人 AI 與 Boss 戰
- 升等選技能系統
- 經驗值寶石收集機制

## 技術

- **引擎**：Godot 4
- **語言**：GDScript
