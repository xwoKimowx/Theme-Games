# Theme Games

高中階段的程式設計練習作品，包含 Python 自學小程式與 Godot 遊戲專案。

## Python 自學程式（40+ 支）

利用課餘時間完成的 Python 練習作品，涵蓋各種題型與應用：

| 類型 | 範例 |
|------|------|
| 數學運算 | 99乘法表、金字塔、阿姆斯壯數、質數 |
| 邏輯題型 | 1A2B、小群體、秘密差、行列最大值 |
| 日期時間 | 月曆、算年紀、閏年、禮拜六生日 |
| 視窗應用 | 紅包抽籤、俄羅斯方塊 |
| 圖像辨識 | PP-OCRv5 車牌辨識（PaddleOCR） |

## Godot 遊戲專案

以 Godot 4 開發的動作生存遊戲，玩法類似吸血鬼倖存者（Vampire Survivors）。

**已完成功能：**
- 主選單介面
- 角色移動與射擊
- 敵人 AI 與 Boss 戰
- 升等選技能系統
- 經驗值寶石收集

**技術：** GDScript / Godot 4
